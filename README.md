抖音评论采集工具
这是一个用于采集抖音视频评论的工具，支持通过关键字搜索视频或直接通过抖音链接获取视频评论区的评论信息。采集的数据包括视频作者、点赞数、评论内容等，并支持导出为 CSV 文件。

功能特性
关键字搜索：

支持按关键字搜索抖音视频。

获取视频的详细信息，包括：

作者信息

点赞数

评论内容

发布时间

视频链接

链接检索：

支持通过抖音视频链接一键检索视频评论区的评论。

提取评论内容、评论者信息、点赞数等数据。

数据导出：

支持将采集到的数据导出为 CSV 文件，方便进一步分析和处理。

多浏览器支持：

支持 Chrome 和 Edge 浏览器，自动适配浏览器驱动。
